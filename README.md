# 商业身份

本地网页工具：把一张名片当成**一次相遇的身份设计**，而不是填空生成的联系卡片。

你先说清四件事——递给谁、在什么场合、希望发生什么、你现在处于哪一段——再可选地放下个人材料。工具据此给出形象立场、对外怎么写、可预览可打印的双面名片，以及中英两份生图提示词。生图模型放到下一阶段。

## 运行

需要 Python 3（只用标准库）。

```bash
python3 server.py
# 浏览器打开 http://127.0.0.1:8765
```

端口可用环境变量改：`PORT=8766 python3 server.py`。草稿存在浏览器 `localStorage`，不上传任何服务器。

## MVP 有什么

- 问询式选择：对象、场合、目的、阶段（均可「其他」自填）
- 个人资料与文件全部可空：表单 + 头像 + 附件（附件只记文件名，不解析 PDF）
- 策略引擎：四维组合 → 立场、信息层级、对外文案、私下提醒（例如在职看机会不印现公司）
- 90×54mm 双面预览，打印/另存 PDF
- 中文、英文生图提示词，可复制

## 不是什么

不是 AI 自动画图，不是多人账号系统，也不是把「求职中」印到给别人的卡上。卡是对外身份；策略说明只给你自己看。
